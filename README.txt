HACK MENU MOD - Fabric 1.21.11 (Java 21)

BUILD (GitHub se, laptop pe kuch install nahi):
1. github.com pe new repo banao, is folder ki saari files upload karo (.github folder ke saath).
2. Actions tab -> "build" run hone do (3-5 min).
3. Run kholo -> Artifacts -> HackMenu-jar download -> zip se andar wali .jar nikalo
   (sources wali jar nahi, jisme "-sources" na ho).

USE:
- Fabric Loader 0.18.4+ aur Fabric API (1.21.11) install karo, .jar ko mods folder me daalo.
- Game me H dabao = menu. (Controls -> Miscellaneous me key badal sakte ho.)
- Effects ke liye world me CHEATS ON hona chahiye (ya OP). Chat me "Applied effect" msgs aate hain;
  band karne ke liye: /gamerule sendCommandFeedback false (1.21.11 me naam send_command_feedback ho sakta hai, Tab dabake dekho)
- Miner 3x3 sirf single player / LAN host me chalta hai.
- X-ray vanilla renderer ke liye hai (Sodium/Iris ke saath nahi chalega).
